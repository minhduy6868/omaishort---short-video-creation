# 1.2 AI-assisted và AI-native

> Nguồn: `README.md` §Providers, `engine/analyzer.py`, `providers/chatgpt_web.py`.

## AI-native — bỏ model là mất sản phẩm

Các stage sau được thiết kế để một model (hoặc fallback thế chỗ model) tạo nội dung video:

| Việc | Native vì |
| --- | --- |
| Lời tin / kiến thức | `write_knowledge_script` gọi ChatGPT web hoặc HTTP LLM trước. Không có JSON thì mới chép wiki |
| Bible và 5 nhịp drama | `analyze_story` |
| Prompt still drama | file `prompts/scene_still.txt` đưa vào chuỗi ảnh |
| Thoại | TTS. Im lặng chỉ khi mọi giọng đều hỏng |

Fallback (`fallback_analyze`, `knowledge_spoken_from_wiki`) vẫn là một phần sản phẩm: job không chết khi model vắng. Nó không biến omaishort thành công cụ không-AI. Chất lượng lời wiki thấp hơn lời model, và `script.json` ghi `provider` để người xem biết đường nào đã chạy.

## AI-assisted — người vẫn quyết định

| Việc | Ai làm |
| --- | --- |
| Dán chuyện, URL, hoặc `--script-brief` | Người dùng studio / CLI |
| Đăng nhập ChatGPT một lần (`--chatgpt-login`) | Người, trên máy đó |
| Chọn kind drama / news / knowledge | Người. Pipeline không tự biến tin thành drama |
| Sửa prompt, schema, test | Người hoặc agent, rồi pytest phủ quyết |
| Giữ hay bỏ diff | Người commit |

Studio không có nút "AI hãy đổi yêu cầu sản phẩm". Prompt trong `prompts/` sinh lời video, không sinh PRD.
