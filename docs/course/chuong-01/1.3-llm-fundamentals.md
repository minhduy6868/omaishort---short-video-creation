# 1.3 Cơ bản về mô hình ngôn ngữ lớn

> Nguồn: `apps/api/omaishort/config.py`, `providers/llm.py`. Repo dùng model có sẵn. Không train.

Ôn ngắn, rồi chỗ code chạm vào.

| Khái niệm | Trong omaishort |
| --- | --- |
| LLM sinh chữ token kế tiếp | Có. Không có classifier, không có model ảnh tự train |
| Chat: system + user | `load_prompt` là system. User là field `kind`, `language`, `SOURCE` |
| Tham số sinh | HTTP payload đặt `temperature` = 0.4. Không set `max_tokens` trong `_complete_http` |
| Model mặc định | `OPENAI_MODEL`, fallback `gpt-4o-mini` |
| Model local / proxy | Nếu base là `127.0.0.1:8080` và tên model là họ GPT, code đổi tên thành `auto` |
| JSON | OpenAI cloud được gửi `response_format: json_object`. ChatGPT web thì không |
| Trọng số, pretrain, RLHF | Không có trong repo. Không có script fine-tune |

Hai đường gọi chữ:

1. **ChatGPT web** — Playwright, profile `DATA_DIR/chatgpt-web`, một hội thoại mỗi ngày. Provider ghi `chatgpt-web`.
2. **HTTP tương thích OpenAI** — `POST {base}/chat/completions`. Provider ghi `llm`.

Ảnh và video là model khác (Pollinations, Gemini, xAI, Wan). Planner không import SDK của chúng. Nó gọi protocol.

> ⚠️ Không có bài tập train model, không có số tham số, không có so sánh loss. Môn học hỏi "cơ bản LLM" — với đồ án này, cơ bản là biết mình đang gọi model người khác và kiểm JSON trước khi dùng.
