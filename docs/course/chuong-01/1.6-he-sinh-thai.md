# 1.6 Hệ sinh thái AI tạo sinh

> Nguồn: `README.md` §Providers, `.cursor/rules/pipeline.mdc`.

Mỗi stage là một chuỗi. Cái đầu trả kết quả thì dừng. Không fork repo nhà cung cấp vào cây này.

| Stage | Thứ tự đang mã |
| --- | --- |
| Script | ChatGPT web → HTTP kiểu OpenAI → wiki / ghi chú README |
| Ảnh | Pollinations → Gemini API → xAI Grok Imagine HTTP → OpenAI images → placeholder |
| Chuyển động drama | xAI video → HF Spaces (`HF_TOKEN`) → WaveSpeed Wan → Pollinations Wan/Seedance → Ken Burns |
| Chuyển động tin / kiến thức | Ken Burns. Không gọi I2V |
| TTS | ElevenLabs → edge-tts → file im lặng |

Việc cố tình không làm:

- Không scrape ChatGPT.com để lấy ảnh, không scrape Gemini / Midjourney / Flow / grok.com.
- Không dùng Pexels.
- Không nhúng template HTML HyperFrames.
- Không để planner import SDK. Adapter nằm trong `apps/api/omaishort/providers/`.

Hệ sinh thái quanh repo (MoneyPrinter, OpenMontage, ArcReel) được ghi ở `docs/RESEARCH.md` để học hợp đồng stage, không để copy mã.

> ⚠️ Không có một màn hình "chọn model" cho người xem. Chọn model là biến môi trường (`.env`) và thứ tự chuỗi trong code.
