# 2.1 Cơ bản về Prompt — omaishort

> Nguồn: `prompts/*.txt`, `apps/api/omaishort/providers/llm.py` (`load_prompt`), `apps/api/omaishort/engine/analyzer.py`.

Một prompt trong omaishort là **hai phần**:

1. **System** — nội dung file trong `prompts/`. Vai trò, luật, hình JSON.
2. **User** — chuỗi lắp lúc chạy: `kind`, `language`, `target_seconds`, `USER_BRIEF`, rồi `SOURCE` hoặc `STORY`.

`load_prompt` chỉ đọc file, không sửa chữ:

```36:37:apps/api/omaishort/providers/llm.py
def load_prompt(name: str) -> str:
    return (PROMPTS_DIR / name).read_text(encoding="utf-8")
```

## File đang dùng

| File | Khi nào | Đầu ra |
| --- | --- | --- |
| `prompts/news_script.txt` | Tin từ URL bài báo | 5 nhịp `hook` … `ending` |
| `prompts/knowledge_script.txt` | Kiến thức / README | cùng 5 khoá |
| `prompts/analyzer_brief.txt` | Analyze news/knowledge | bible narrator + `structure` |
| `prompts/analyzer.txt` | Analyze drama | bible mặt + 5 nhịp |
| `prompts/planner.txt`, `planner_brief.txt` | Plan cảnh | storyboard |
| `prompts/scene_still.txt`, `scene_still_brief.txt` | Prompt ảnh | mô tả still |
| `prompts/character_ref.txt`, `location_ref.txt`, `prop_ref.txt` | Ảnh hộ chiếu / bối cảnh / đạo cụ | prompt ảnh ref |

Tin chọn `news_script.txt` ngay trong pipeline (`prompt_name="news_script.txt"`). Kiến thức để mặc định `knowledge_script.txt` trong `write_knowledge_script`.

User message của script được ghép tại `knowledge_script_user`: `title`, `topic`, `language`, `target_seconds`, `USER_BRIEF` nếu có, rồi `SOURCE` tối đa 8000 ký tự (`analyzer.py`).
