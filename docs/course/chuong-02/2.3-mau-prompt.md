# 2.3 Các mẫu prompt (Prompt Patterns)

> Nguồn: `prompts/news_script.txt`, `prompts/analyzer_brief.txt`. Tên mẫu dưới đây là cách gọi của môn học, ánh xạ lên đoạn chữ thật.

| Mẫu | Chỗ trong prompt |
| --- | --- |
| Persona | Dòng vai: news writer / editorial analyzer / documentary host |
| Recipe | Mục `Beats:` — hook, conflict, rising_action, twist, ending, mỗi nhịp một việc |
| Template | Khối `JSON shape` với năm chuỗi |
| Context sandwich | `Facts:` và `USER_BRIEF:` kẹp giữa vai và JSON: được nhấn mạnh gì, không được bịa gì |
| Refusal / boundary | "SOURCE is not omaishort. Do not describe a video factory." |

Analyzer brief thêm một persona phụ trong bible: đúng một nhân vật `narrator`, `appearance` = `not on camera`. Đó là mẫu **output constraint**, không phải mẫu "hãy sáng tạo thêm nhân vật".

Drama dùng `prompts/analyzer.txt` (không phải file brief). File đó cho phép bible mặt người. Hai file là hai mẫu, không trộn.

> ⚠️ Không có mẫu "flipped interaction" (model hỏi lại người dùng) hay "cognitive verifier" (model tự chấm rồi viết lại). Job chạy một lượt rồi nhận JSON hoặc bỏ.
