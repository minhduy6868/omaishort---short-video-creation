# 2.5 Đầu ra có cấu trúc (Structured Outputs)

> Nguồn: `prompts/news_script.txt`, `apps/api/omaishort/providers/llm.py`, `apps/api/omaishort/engine/analyzer.py`.

Hợp đồng script là năm chuỗi:

```json
{
  "hook": "...",
  "conflict": "...",
  "rising_action": "...",
  "twist": "...",
  "ending": "..."
}
```

Analyzer (`analyzer_brief.txt`) bọc thêm `bible` và `structure` (các nhịp cộng `hook_sec` … `ending_sec`).

## Cách code ép JSON

1. Prompt viết "Return ONLY valid JSON. No markdown."
2. `parse_llm_json` đọc chữ model trả.
3. Với HTTP trỏ `api.openai.com` và có `OPENAI_API_KEY`, payload thêm `response_format: {type: json_object}`. Nếu server 400 vì field đó, code bỏ field rồi gọi lại (`llm.py`, `_complete_http`).
4. `_beats_from_script` từ chối bản thiếu nhịp hoặc nhịp dưới 8 từ. Bản bị từ chối không được vá bằng cách bịa nhịp; job rơi fallback.

ChatGPT web **không** gửi `response_format`. Nó dựa vào lệnh "ONLY valid JSON". Nếu web trả không phải JSON, `complete_json_result` ghi lỗi và thử HTTP LLM.

> ⚠️ Không có JSON Schema đầy đủ (kiểu, minLength) gửi lên model. Pydantic kiểm bible/structure **sau** khi JSON đã về (`CharacterBible.model_validate` trong `analyze_story`). Script năm nhịp được kiểm bằng `_beats_from_script`, không bằng model schema.
