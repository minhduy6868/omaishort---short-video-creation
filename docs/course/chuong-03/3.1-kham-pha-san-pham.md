# 3.1 Khám phá Sản phẩm (Product Discovery) — omaishort

> Nguồn: `docs/REQUIREMENTS.md` §1–§3, `docs/AUTH.md` §1–§2, `docs/RESEARCH.md`, `.cursor/rules/pipeline.mdc`.

## 3.1.1 Vấn đề (Problem)

Trích nguyên văn hợp đồng sản phẩm (`docs/REQUIREMENTS.md` §1):

> "Creators need **one** 1080×1920 short from a paste."

Tức là: người sáng tạo dán một đoạn văn / ý tưởng / URL và cần **một video dọc 1080×1920** hoàn chỉnh (có lồng tiếng + phụ đề), không phải một bộ công cụ dựng phim.

Vấn đề vận hành thứ hai (từ `docs/AUTH.md` §1): trước khi có auth, "anyone who can hit `127.0.0.1:8765` can create jobs and **read every file under `data/`**" — không có mô hình tài khoản. Đây là lý do sinh ra tính năng auth + attachment.

## 3.1.2 Sản phẩm là gì / không là gì

Từ `.cursor/rules/pipeline.mdc` và `docs/REQUIREMENTS.md`:

- **Là:** một engine biến câu chuyện thành short, **ba loại trên một pipeline**.
- **Không là:** "a TikTok clone", không fork MoneyPrinter/OpenMontage/HyperFrames, không phải kho lưu MP4 người dùng.

Ba loại sản phẩm (`VideoKind` trong `packages/schema/omaishort_schema/models.py`):

| Kind | Bản chất (REQUIREMENTS §1) |
| --- | --- |
| `drama` | Video truyện ngắn: khuôn mặt theo Character Bible, có chuyển động (I2V nếu có key) |
| `news` | **Ảnh ghép** biên tập: ảnh bài báo + Ken Burns, giọng dẫn |
| `knowledge` | **Ảnh ghép** biên tập: ảnh minh hoạ + Ken Burns, VO viết trước |
| `brief` | Alias cũ → tự quy về `news` (`coerce_video_kind`) |

```52:63:packages/schema/omaishort_schema/models.py
class VideoKind(str, Enum):
    drama = "drama"
    news = "news"
    knowledge = "knowledge"
    brief = "brief"  # legacy alias of news


def is_editorial(kind: VideoKind | str | None) -> bool:
    value = kind.value if isinstance(kind, VideoKind) else str(kind or "")
    return value in {VideoKind.news.value, VideoKind.knowledge.value, VideoKind.brief.value}
```

## 3.1.3 Đối tượng người dùng (Personas / Actors)

Repo định nghĩa người dùng ở hai chỗ và chúng khớp nhau:

`docs/REQUIREMENTS.md` §2 (Users):

| User | Việc của họ | Bề mặt |
| --- | --- | --- |
| Creator | Đăng ký/đăng nhập, dán, đính kèm ref, chờ, tải MP4 | Studio `apps/web` |
| Operator | Người dùng HTTP đầu tiên (`role=operator`); CLI không cần login | Studio + `python -m omaishort` |
| Agent | Sửa pipeline mà không phá bible/scene/timeline | REQUIREMENTS + AUTH + AGENTS.md |

`docs/AUTH.md` §2 (Actors) bổ sung **Anonymous** (chỉ vào được `/health`, `/`, `/docs`, `/providers`, `/voices`) và **Agent/CI** (pytest với DB tạm).

Vai trò được **thực thi trong code**, không chỉ là mô tả — người đầu tiên là `operator`, còn lại là `creator`:

## 3.1.4 Định vị cạnh tranh (chỉ ở góc độ kỹ thuật)

`docs/RESEARCH.md` là bản đồ đối thủ/hệ sinh thái, nhưng khung nhìn là **"steal contracts, don't fork"**: học stage order + contract từ MoneyPrinter (ops), OpenMontage (gates/skills), ArcReel/FTL/Story Forge (bible → still → I2V), HyperFrames (5-beat editorial), và các model I2V (Wan/LTX/Seedance/Veo/Grok) đặt sau protocol `VideoProvider`.

## 3.1.5 Jobs-to-be-done (suy ra từ input contract)

Suy ra trực tiếp từ các nhánh xử lý input thật trong `apps/api/omaishort/cli.py` (`_run`) và `StoryInput`:

- "Tôi dán một kịch bản/ý tưởng drama → ra short truyện." (`kind=drama`, `mode=script|idea`)
- "Tôi dán URL bài báo → ra bản tin ảnh ghép đến tận kết." (`looks_like_url` → `news`)
- "Tôi dán URL GitHub → ra video giải thích dự án." (`looks_like_github` → `knowledge`)
- "Tôi dán một chủ đề ngắn → ra video kiến thức, VO viết trước." (`is_knowledge_topic`, REQUIREMENTS §7)
