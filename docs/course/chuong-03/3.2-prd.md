# 3.2 Tài liệu Yêu cầu Sản phẩm (PRD) — omaishort

> ⚠️ **Không có trong code:** repo **chưa có** file PRD độc lập. `docs/REQUIREMENTS.md` tự nhận vai trò *"product contract"*. Tài liệu này **tổng hợp lại** thành bố cục PRD từ những gì có thật trong REQUIREMENTS / AUTH / RESEARCH và code. Mọi mục đều dẫn nguồn; không thêm giả định thương mại.

## 3.2.1 Tổng quan (Overview)

omaishort là **Story → short-video engine**, local-first, chạy trên Windows. Một pipeline, ba loại đầu ra (`drama` / `news` / `knowledge`), xuất MP4 dọc 1080×1920.

Kiến trúc (REQUIREMENTS §5): Studio (`apps/web`, Vite+React) hoặc CLI → FastAPI + PostgreSQL → engine chạy các stage → MP4.

## 3.2.2 Mục tiêu (Goals) — bất biến sản phẩm

Lấy từ `docs/REQUIREMENTS.md` §0 (Invariants) — "A change is out of product if it breaks any of these":

1. Output luôn **1080×1920 @ 30fps**; thời lượng `render/short.mp4` = **VO đã probe** (không phải `target_seconds`).
2. **Một still / scene**; mọi shot trong scene chia sẻ `still_id`.
3. Beats luôn là `hook → conflict → rising_action → twist → ending`.
4. Mặt drama từ **Character Bible passport**; news/knowledge là ảnh ghép, `characters=[]`, `use_face_ref=false`.
5. Ken Burns không bao giờ bị gắn nhãn I2V; `render/motion.json` = `kenburns | i2v | mixed`.
6. Planner không import SDK vendor; image/video/TTS/LLM đứng sau protocol.
7. Không Pexels, không HyperFrames HTML, không scrape UI Gemini/Midjourney, không vendoring AGPL.
8. Secrets ở `.env`; CI không cần key; không commit `data/jobs/`.
9. HTTP jobs và `/files` là **theo từng user**; Studio bắt buộc đăng nhập; CLI jobs `user_id=null`.

## 3.2.3 Ngoài phạm vi (Non-goals)

`docs/REQUIREMENTS.md` §12 + `docs/AUTH.md` §10:

- P3: review gates, contact sheet, `POST /jobs/{id}/approve`, khoá `render_runtime`.
- P5: preset gateway đặt tên (`ollama`/`openrouter` là config hạng nhất).
- P6: nhà máy Part 1..N, edit-agent "scene 5 darker", Redis queue.
- Không bao giờ mặc định: Pexels, HyperFrames, copy AGPL, tự đăng mạng xã hội, scrape UI.
- Auth: không hosted IdP, 2FA, email verify, S3 attachments, `/files` công khai.

## 3.2.4 Phạm vi tính năng (Scope) — MVP hiện tại

| Nhóm | Tính năng (có trong code) | Nguồn |
| --- | --- | --- |
| Tạo video | 3 kind, 5 beat, một still/scene, Ken Burns / I2V | REQUIREMENTS §5–§9 |
| Nhập liệu | paste text / ý tưởng / URL bài báo / URL GitHub / topic kiến thức | `cli.py`, REQUIREMENTS §4, §7 |
| Provider chain | LLM, image, video, TTS đều fallback theo bậc | REQUIREMENTS §8–§9, RESEARCH §F |
| Tài khoản | register/login/refresh/logout, JWT + refresh xoay, khoá | AUTH §3, `auth.py` |
| Attachment | upload face/location/prop/editorial/logo/script, quota, sniff | AUTH §6, `uploads.py` |
| File riêng tư | `/files/{path}` có auth + kiểm soát sở hữu | AUTH §5.4, `files.py` |

## 3.2.5 Ràng buộc phi chức năng (Constraints)

`docs/REQUIREMENTS.md` §11 (tóm tắt): local-first Windows (NFR1), chỉ dùng protocol không import SDK (NFR2), bảo mật `.env`/scrypt/refresh xoay/ownership (NFR3), output 1080×1920 30fps = VO (NFR4), sản phẩm `en`/`vi` (NFR5), test không gọi mạng thật (NFR6), ChatGPT một `/c/` mỗi ngày (NFR7), thất bại phải ghi lý do (NFR8).

## 3.2.6 Stack

`docs/REQUIREMENTS.md` §14: Python 3.11, FastAPI, Pydantic v2, PostgreSQL (`DATABASE_URL`; pytest có thể dùng SQLite tạm), Vite + React, FFmpeg. Tuỳ chọn: Playwright ChatGPT web, Gemini image HTTP, xAI Grok Imagine image/video HTTP, LLM OpenAI-compatible, ComfyUI, ElevenLabs, faster-whisper, HF Spaces, WaveSpeed HTTP, Pollinations Wan.

## 3.2.7 Tiêu chí thành công (Success criteria)

> ⚠️ **Không có KPI sản phẩm** (retention, thời gian tạo, mức hài lòng). Repo chỉ có **acceptance kỹ thuật** (REQUIREMENTS §13):

- `pytest -q` từ gốc repo xanh.
- `npx tsc --noEmit` trong `apps/web` xanh.
- `python -m omaishort samples/confession-60s.md` → MP4 1080×1920 có tiếng.
- `python -m omaishort samples/knowledge-topic.md --kind knowledge --language vi` → explainer; `script.json` ghi provider; không có mặt bible trên hình.
- News URL (`--kind news`) phủ đến kết bài; still khớp beat.
- `POST /jobs` ẩn danh trả 401; đoán id người khác trả 404; `/files` chặn `omaishort.db`.

## 3.2.8 Change gate (quản trị thay đổi PRD)

`docs/REQUIREMENTS.md` §15: cùng một PR **phải** cập nhật REQUIREMENTS khi đổi: cặp beat lens, số scene, waterfall still, luật session ChatGPT, **thứ tự** provider image/TTS/video, field của `StoryInput`, job stages, hoặc luật auth/attachment. Không "sửa chất lượng" bằng cách thêm bề mặt sản phẩm mới.
