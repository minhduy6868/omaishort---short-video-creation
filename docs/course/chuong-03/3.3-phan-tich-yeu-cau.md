| `text` | ≥8 ký tự sau khi fetch |
| `target_seconds` | 15–180, default 60; CLI `--seconds 0` → 90 (news/knowledge) / 60 (drama) |

## 3.3.4 Mô hình dữ liệu (Data model)

**Auth/attachment** (`docs/AUTH.md` §4, thực thi ở `apps/api/omaishort/db.py`):

- `users`: id (12-hex), email (unique, lowercase), password_hash (scrypt), display_name, role (`creator`|`operator`), failed_logins, locked_until, timestamps. `public_user()` **không** trả hash/failed/locked.
- `refresh_tokens`: id, user_id, token_hash (SHA-256), expires_at, revoked_at, created_at, user_agent (≤200).
- `attachments`: id, user_id, kind, filename, mime, byte_size, sha256, rel_path, created_at. Trên đĩa: `data/attachments/<user_id>/<id><ext>`.
- `jobs.user_id`: NULL = CLI job; HTTP luôn set.

**Nội dung video** (schema Pydantic, `models.py`): `CharacterBible` (characters/locations/props) → `StoryStructure` (5 beat + \*_sec) → `Storyboard` (scenes) → mỗi `Scene` có `still_id` + `shots[]` (mỗi `Shot` = camera/motion/t_start/t_end/still_id) → `Timeline` (1080×1920, 30fps, elements/text/audio) mà Remotion chỉ đọc file này.

Ràng buộc bất biến được **ép ở tầng schema** (không chỉ tài liệu):

```261:266:packages/schema/omaishort_schema/models.py
    @model_validator(mode="after")
    def shots_share_still(self) -> Scene:

                raise ValueError("every shot in a scene must share the scene still_id")
```
