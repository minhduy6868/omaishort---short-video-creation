# 3.4 User Stories & Tiêu chí Chấp nhận — omaishort

> ⚠️ **Không có trong code:** repo **không** có user story viết sẵn dạng "As a… I want…" hay Given/When/Then. Toàn bộ story dưới đây được **suy ra** từ endpoint thật (`apps/api/omaishort/main.py`), input contract (`StoryInput`), và **map tiêu chí chấp nhận vào test thật** (`tests/test_auth.py`, `tests/test_attachments.py`) và acceptance kỹ thuật (REQUIREMENTS §13, AUTH §11). Mỗi story ghi rõ "Kiểm chứng bởi".

Quy ước: **AC** = Acceptance Criteria (Given → When → Then).

---

## Epic A — Tài khoản (Creator/Operator)

### US-A1 — Đăng ký tài khoản
**Là** người sáng tạo, **tôi muốn** đăng ký bằng email + mật khẩu, **để** sở hữu job và file của mình.

- AC1: Given chưa có user nào, When `POST /auth/register`, Then user đầu tiên có `role=operator`.
- AC2: Given đã có user, When đăng ký tiếp, Then user mới có `role=creator` (nếu `AUTH_SIGNUP=1`).
- AC3: Given `AUTH_SIGNUP=0` và đã có operator, When đăng ký, Then **403 signup closed**.
- AC4: Response 201 trả `{ user, access_token, token_type: "bearer", expires_in: 900, refresh_token }` + Set-Cookie.

**Kiểm chứng bởi:** `tests/test_auth.py::test_register_login_me_cookie`, `::test_second_user_is_creator_and_cannot_read_foreign_job`; code `apps/api/omaishort/auth.py::register_user`.

### US-A2 — Đăng nhập & phiên bền
**Là** người dùng, **tôi muốn** đăng nhập và giữ phiên qua cookie, **để** ảnh/video `<img>/<video>` tải được mà không cần gắn token.

- AC1: `POST /auth/login` đúng → 200 + cookie `omaishort_at` (900s) và `omaishort_rt` (14 ngày).
- AC2: `GET /auth/me` chạy được **chỉ với cookie**.
- AC3: Sai mật khẩu → **401** với thông điệp chung `invalid email or password` (không lộ email tồn tại hay không).
- AC4: Sau **8** lần sai → khoá **15 phút** → **429**.

**Kiểm chứng bởi:** `tests/test_auth.py::test_register_login_me_cookie`, `::test_unknown_login_is_generic`; code `authenticate` (khoá 8 lần/15 phút), `config.AUTH_ACCESS_TTL_SEC=900`, `AUTH_REFRESH_TTL_SEC=14*24*3600`.

### US-A3 — Refresh xoay & chống trộm token
**Là** hệ thống, **tôi muốn** xoay refresh token mỗi lần refresh, **để** thu hồi được khi bị dùng lại.

- AC1: `POST /auth/refresh` → cấp access mới + refresh mới; refresh cũ bị `revoked_at`.
- AC2: Dùng lại refresh **đã thu hồi** → thu hồi **toàn bộ** refresh của user đó → 401.

**Kiểm chứng bởi:** `tests/test_auth.py::test_refresh_rotates_and_reuse_revokes`; code `auth.py::rotate_refresh`.

### US-A4 — Đăng xuất
**Là** người dùng, **tôi muốn** đăng xuất, **để** phiên bị vô hiệu.

- AC1: `POST /auth/logout` → 204, xoá cookie, thu hồi refresh đang trình.
- AC2: refresh cũ sau logout → 401.

**Kiểm chứng bởi:** `tests/test_auth.py::test_logout_revokes_refresh`.

### US-A5 — Token/hạn/khoá an toàn (bảo mật)
- AC1: token dị dạng (không phải JWT hợp lệ) → **401**, không 500.
- AC2: user đang bị khoá không dùng được JWT cũ còn hạn.

**Kiểm chứng bởi:** `tests/test_auth.py::test_malformed_bearer_is_401_not_500`, `::test_locked_user_cannot_use_existing_jwt`; code `decode_access`, `get_current_user`.

## Epic B — Tạo & xem video

### US-B1 — Tạo job (bắt buộc đăng nhập)
**Là** creator, **tôi muốn** gửi câu chuyện để tạo short, **để** nhận MP4.

- AC1: `POST /jobs` **không auth** → 401.
- AC2: Có auth → 200 `{ id, status: "queued" }`, `jobs.user_id` = caller, chạy nền.
- AC3: Nếu bất kỳ attachment id nào không tồn tại/không sở hữu → 404 (validate ngay tại `POST /jobs`).

**Kiểm chứng bởi:** `tests/test_auth.py::test_jobs_require_auth`; code `main.py::create_job` + `uploads.load_job_files`.

### US-B2 — Cô lập quyền sở hữu job
**Là** creator, **tôi muốn** chỉ đọc job của mình, **để** dữ liệu riêng tư.

- AC1: Creator B `GET /jobs/{id}` của A → **404** (không 403, để không lộ id).
- AC2: Operator đọc được job `user_id=NULL` (job CLI) khi biết id.
- AC3: `GET /jobs/{id}` trả `public_job()` — không lộ `*_json` thô, không lộ hash.

**Kiểm chứng bởi:** `tests/test_auth.py::test_second_user_is_creator_and_cannot_read_foreign_job`, `::test_operator_can_read_cli_job`; code `auth.py::can_read_job`.

### US-B3 — Liệt kê & tải MP4
- AC1: `GET /jobs?limit=1..50` (default 20) trả job của mình, mới nhất trước.
- AC2: `GET /jobs/{id}/download` chỉ trả MP4 **nằm trong `DATA_DIR`** (chặn path traversal), ngược lại 404.

**Kiểm chứng bởi:** code `main.py::list_job_rows`, `::download_mp4` (kiểm `relative_to(DATA_DIR)`).

### US-B4 — Ba loại đầu ra
**Là** creator, **tôi muốn** chọn drama/news/knowledge, **để** ra đúng định dạng.

- AC1: drama → truyện 5 beat, mặt bible, 8–15 scene.
- AC2: news URL → phủ đến kết bài, đúng 5 beat, ảnh ghép, không mặt bible.
- AC3: knowledge topic → `script.json` tồn tại **trước** stills, ghi provider.

**Kiểm chứng bởi:** REQUIREMENTS §13 acceptance (chạy `samples/*.md`); code `cli.py`, `engine/`.

> US-B4 là story "ô dù". US-B5..US-B10 dưới đây tách nhỏ theo từng kind để mỗi AC map được **một test có thật**.

### US-B5 — Drama: chọn cách kể (`drama_shape`)
**Là** creator, **tôi muốn** quyết định truyện được kể theo shape viral hay theo đúng kịch bản của tôi, **để** AI không bẻ câu chuyện của tôi thành công thức.

- AC1: Given không truyền `drama_shape`, When tạo `StoryInput`, Then giá trị là `infer`.
- AC2: Given `drama_shape` đã đặt, When dựng user blob cho analyze, Then shape xuất hiện trong prompt (AI biết phải theo shape nào).
- AC3: Given paste là kịch bản hội thoại (`Tên: lời`), When analyze, Then VO là **lời thoại**, không phải văn tường thuật.
- AC4: Given kịch bản mẫu, When plan fallback, Then số scene đủ ngưỡng drama (không rơi về vài scene).

**Kiểm chứng bởi:** `tests/test_schema.py::test_story_input_drama_shape_defaults_to_infer`; `tests/test_engine.py::test_analyze_user_includes_drama_shape`, `::test_dialogue_script_is_speech_not_narration`, `::test_fallback_sample_script_has_enough_scenes`.

### US-B6 — Drama: khoá nhận dạng nhân vật (Character Bible)
**Là** creator, **tôi muốn** cùng một nhân vật giữ nguyên mặt/quần áo qua mọi cảnh, **để** video trông như một bộ phim chứ không phải ảnh của 5 người lạ.

- AC1: Given một scene chỉ có vợ trên hình, When dựng image prompt, Then prompt **không** kéo chồng vào; chỉ cast on-camera + trang phục.
- AC2: Given đã có passport, When dựng URL Kontext, Then dùng passport **nhân vật**, không phải ảnh location.
- AC3: Given scene có mặt + địa điểm + đạo cụ, When gom refs, Then thứ tự là faces → location → props.
- AC4: Given bible đã phân tích, When sinh prompt, Then quan hệ và personality được giữ nguyên (khoá tính cách, không mô tả lại mặt).
- AC5: Given cùng một `character.id`, When gọi Pollinations, Then seed ổn định (cùng người ra cùng khuôn).

**Kiểm chứng bởi:** `tests/test_engine.py::test_husband_only_when_on_camera`, `::test_scene_still_refs_order_faces_then_location_then_props`, `::test_analyze_stamps_relationship_locks`, `::test_still_prompt_keeps_personality_lock`; `tests/test_render.py::test_compact_scene_prompt_keeps_only_cast_and_wardrobe`, `::test_kontext_url_uses_character_passport_not_location`, `::test_pollinations_seed_stable_for_same_character`.

### US-B7 — Drama: chuyển động trung thực (I2V hoặc Ken Burns)
**Là** creator, **tôi muốn** biết video thật sự có chuyển động hay chỉ là ảnh zoom, **để** không bị đánh lừa về chất lượng.

- AC1: Given storyboard drama, When `normalize_storyboard` chạy, Then shot bị **ghi đè** theo beat lens (không giữ hold/zoom ngẫu nhiên của LLM).
- AC2: Given một scene, When dựng motion prompt, Then chỉ có camera + hành động — **không** đổ bible/VO vào.
- AC3: Given scene kế tiếp đổi hẳn dàn diễn viên, When chọn last frame, Then **không** bridge (tránh morph mặt vợ thành chồng).
- AC4: Given kind là news/knowledge, When hỏi "có cần I2V không", Then trả lời **không** (ảnh ghép giữ Ken Burns).
- AC5: Given clip sinh ra, When kiểm khung hình, Then luôn dọc 9:16.

**Kiểm chứng bởi:** `tests/test_engine.py::test_beat_shots_follow_drama_lenses`, `::test_normalize_applies_beat_lenses_to_llm_shots`, `::test_motion_prompt_is_camera_and_action_not_bible_dump`, `::test_end_frame_bridges_same_cast_not_strangers`, `::test_i2v_wanted_skips_editorial_collage`; `tests/test_render.py::test_kenburns_clip_is_vertical`, `::test_xai_video_body_is_vertical_i2v`.

### US-B8 — News: phủ hết bài báo bằng ảnh ghép biên tập
**Là** creator, **tôi muốn** bản tin kể đến tận kết bài và ảnh khớp từng đoạn, **để** video không cụt ở đoạn xung đột.

- AC1: Given kind news, When plan, Then **không** có nhân vật/mặt người trên hình.
- AC2: Given bài báo có đoạn kết, When trích + plan, Then beat cuối phủ **phần kết**, không dừng ở xung đột.
- AC3: Given bài dài, When viết VO, Then VO là **tóm tắt nói được**, không copy nguyên bài.
- AC4: Given mỗi beat, When tìm ảnh, Then search term bám **VO của beat đó**, không bám headline.
- AC5: Given gallery bài mỏng hoặc tải ảnh lỗi, When gom still, Then bỏ qua logo và **fallback sang ảnh CC**.
- AC6: Given ảnh ngang, When dựng khung, Then letterbox về 9:16 và giữ medium/wide (**không** punch-in close-up).

**Kiểm chứng bởi:** `tests/test_engine.py::test_brief_plan_has_no_faces`, `::test_news_last_beat_covers_article_ending`, `::test_brief_vo_is_a_short_summary_not_the_article`, `::test_editorial_beat_shots_stay_in_frame`, `::test_editorial_beat_lenses_skip_close_up`; `tests/test_brief_media.py::test_extract_keeps_article_ending`, `::test_visual_terms_for_beat_follow_the_vo_not_the_headline`, `::test_extract_article_images_skips_logos`, `::test_assign_retries_cc_when_article_download_fails`, `::test_collect_fills_thin_article_gallery`, `::test_conform_photo_letterboxes_wide_stills`.

### US-B9 — Knowledge: viết lời bình trước (script-first)
**Là** creator, **tôi muốn** VO được viết trước rồi mới sinh ảnh, **để** ảnh minh hoạ bám đúng nội dung nói.

- AC1: Given kind knowledge, When định tuyến, Then được coi là **editorial** (ảnh ghép, không mặt bible).
- AC2: Given có LLM, When viết script, Then ưu tiên LLM; Given LLM hỏng, Then **fallback wiki** (không fail job).
- AC3: Given có `--script-brief`, When dựng user blob, Then brief xuất hiện trong yêu cầu gửi LLM.
- AC4: Given paste dạng "thuyết minh về …", When sinh VO/plan, Then **không** lặp lại câu yêu cầu của người dùng.
- AC5: Given URL GitHub, When lấy facts, Then dùng README/topics/docs/homepage của repo và chuyển thành **văn nói**.
- AC6: Given wiki fallback, When viết VO, Then đủ **5 beat** và không dùng khẩu hiệu tượng đài.
- AC7: Given nhiều job trong cùng ngày, When dùng ChatGPT web, Then tái sử dụng **một thread/ngày**.

**Kiểm chứng bởi:** `tests/test_engine.py::test_knowledge_kind_is_editorial`, `::test_knowledge_topic_plan_does_not_echo_the_request`, `::test_knowledge_plan_keeps_hooky_readme_beats`; `tests/test_brief_media.py::test_write_knowledge_script_prefers_llm`, `::test_write_knowledge_script_falls_back_to_wiki`, `::test_knowledge_script_user_includes_brief`, `::test_knowledge_topic_query_strips_request_shell`, `::test_github_readme_becomes_spoken_prose`, `::test_github_project_notes_merge_topics_docs_homepage`, `::test_knowledge_spoken_biography_fills_five_beats`, `::test_knowledge_spoken_hung_kings_is_a_legend_not_a_statue_slogan`, `::test_chatgpt_web_reuses_one_chat_url_per_day`.

### US-B10 — Đầu ra chung: đồng hồ audio, phụ đề, mix
**Là** creator, **tôi muốn** MP4 đúng khổ, phụ đề khớp tiếng và tuỳ chọn logo/nhạc nền, **để** đăng được ngay.

- AC1: Given job hoàn tất, When kiểm MP4, Then **1080×1920 có audio**.
- AC2: Given audio thật dài khác dự kiến, When rescale, Then thời lượng scene/shot **khớp audio đã probe**.
- AC3: Given `SubtitleStyle`, When sinh ASS, Then đúng cỡ chữ và ngắt theo câu (giữ dấu câu).
- AC4: Given `mix.logo_enabled`, When compose, Then logo được overlay.
- AC5: Given kind editorial, When ghép 5 beat, Then có `xfade` giữa các beat và zoompan **mạnh hơn** drama.

**Kiểm chứng bởi:** `tests/test_render.py::test_compose_writes_1080x1920_with_audio`, `::test_compose_overlays_logo_when_enabled`; `tests/test_engine.py::test_rescale_matches_audio`, `::test_words_to_ass_uses_font_size`, `::test_captions_keep_punct_and_break_on_sentences`, `::test_editorial_xfade_offsets_overlap_between_beats`, `::test_editorial_zoompan_is_stronger_than_drama`.

## Epic C — Attachment (tài sản người dùng)

### US-C1 — Upload có kiểm duyệt
**Là** creator, **tôi muốn** upload ảnh/khuôn mặt/logo/script, **để** đưa vào video.

- AC1: `POST /attachments?kind=` (multipart) → sniff magic bytes; chỉ jpeg/png/webp (ảnh) hoặc txt/md UTF-8 (script).
- AC2: Từ chối SVG và file quá cỡ (face/location/prop/editorial ≤8MiB, logo ≤2MiB, script ≤256KiB).
- AC3: Quota: ≤80 file, ≤200MiB/user; trùng sha256+kind → trả lại row cũ (không lưu bản thứ hai).

**Kiểm chứng bởi:** `tests/test_auth.py::test_upload_png_and_reject_svg`; code `uploads.py` (`sniff_bytes`, `max_bytes_for`, `attachment_quota`).

### US-C2 — Bind attachment vào pipeline đúng loại
**Là** creator, **tôi muốn** file được dùng đúng chỗ, **để** không phá quy tắc sản phẩm.

- AC1: `face` bind `wife` trên drama → copy vào `refs/wife.png`, bỏ qua sinh passport.
- AC2: `editorial` trên news → thắng waterfall, là still đầu tiên.
- AC3: `editorial` bị **bỏ qua** trên drama; `face` bị **bỏ qua** trên news.
- AC4: `logo` → set `mix.logo_enabled` + path; `script` → copy làm provenance, **không** thay `text`.

**Kiểm chứng bởi:** `tests/test_attachments.py::test_face_attachment_writes_passport`, `::test_editorial_ignored_on_drama`, `::test_face_ignored_on_news`, `::test_editorial_local_stills_win`, `::test_logo_and_script_copy`.

## Epic D — File riêng tư

### US-D1 — Phục vụ file có xác thực
**Là** hệ thống, **tôi muốn** `/files` yêu cầu đăng nhập + kiểm sở hữu, **để** không lộ `data/`.

- AC1: `GET /files/{path}` ẩn danh → 401 (không liệt kê thư mục).
- AC2: `/files/omaishort.db` và `/files/.auth_secret` → 404 kể cả đã đăng nhập.

**Kiểm chứng bởi:** `tests/test_auth.py::test_files_hide_db_and_secret`; code `files.py::resolve_public_file`.
