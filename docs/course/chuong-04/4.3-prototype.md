# 4.3 Tạo bản mẫu (Prototyping)

Bản mẫu của omaishort là **app đang chạy**, không phải bản click giả.

| Lớp | Chạy bằng |
| --- | --- |
| Studio | `apps/web` — Vite. Dev proxy `/jobs`, `/auth`, `/files` tới `127.0.0.1:8765` |
| API | `python -m omaishort` trong `apps/api` |
| Desktop | `desktop.py` phục vụ `apps/web/dist` cùng origin với API |

Luồng bấm được kiểm bằng route thật ở [4.1](4.1-user-flow.md): landing → login → news → watch. Poll `GET /jobs/{id}` mỗi 1.5s đến `done` hoặc `failed` (luật frontend).

Prototype không gồm:

- dữ liệu giả cho still (placeholder chỉ khi provider ảnh không trả ảnh thật, và pipeline ghi rõ)
- nhãn Ken Burns giả thành I2V — nếu có `artifacts.motion` thì UI hiện đúng mode đó

> ⚠️ Không có prototype tách nhánh "chỉ UI, không API". Bài thực hành 4 đi trên route đã nối backend.
