# 4.4 AI đánh giá thiết kế (AI Design Review)

Repo **không** gọi model để chấm layout, contrast, hay thứ tự nút.

Chỗ đứng của "review" hôm nay:

| Việc | Ai làm | File |
| --- | --- | --- |
| Cấm font Inter, cấm gradient tím kiểu "AI" | luật cho người/agent sửa UI | `.cursor/rules/frontend.mdc` |
| Cấm gắn nhãn Ken Burns thành I2V | cùng file + `quality.mdc` | UI đọc `artifacts.motion` |
| Cấm thêm thư viện UI khi trang không cần | `frontend.mdc` | — |
| Route studio không đè prefix API `/jobs` | `frontend.mdc`, `nav.tsx` | — |

Một review thiết kế bằng AI, nếu làm sau này, chỉ được phép đối chiếu những luật đó và ảnh chụp màn hình. Nó không được đề xuất biến trang tin thành drama, không được thêm màn duyệt từng ảnh.

Kết quả review có thật trong đợt landing: route `/en` là landing, `/` trên desktop là studio, và CTA `/work` vẫn đi qua cổng login. Đó là sửa code (`main.tsx`), không phải bản nhận xét model lưu trong repo.

> ⚠️ Không có artifact `design-review.json`, không có prompt "critique this screen".
