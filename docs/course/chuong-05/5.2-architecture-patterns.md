# 5.2 Các mô hình kiến trúc (Architecture Patterns)

## Pipeline theo stage

Một job là một ống tuần tự trong `run_job`, không phải event bus. Mỗi stage ghi tiến độ vào hàng `jobs` (`stage`, `progress`) và ghi file artifact. Hỏng ở giữa thì `status=failed` và `error`, không nhảy stage.

## Chuỗi provider (chain of responsibility)

Ảnh, lời, video mỗi loại là một danh sách triển khai. Cái đầu trả kết quả thì dừng. Planner không import SDK.

Ảnh (`providers/image.py`, protocol `ImageProvider`): Pollinations → Gemini → xAI → OpenAI → placeholder. Comfy là stub khi không cần ảnh chụp.

Lời (`complete_json_result`): ChatGPT web nếu đã login → HTTP LLM → rỗng, rồi engine tự viết fallback.

Video drama: xAI → HF Spaces → WaveSpeed → Pollinations → Comfy stub → Ken Burns. News và knowledge không đi I2V; `compose.py` ghi `motion.json` mode `kenburns` khi không có clip I2V.

## Monolith có cổng cloud hẹp

Chỉ metadata có thể sang D1. File ở đĩa máy chạy job. Không có pattern "mọi thứ trên CDN".

> ⚠️ Không có hexagonal architecture đặt tên, không có plugin loader động. Thêm nhà cung cấp là viết class protocol rồi nối vào chuỗi có sẵn.
