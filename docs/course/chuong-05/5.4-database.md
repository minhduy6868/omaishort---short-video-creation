# 5.4 Thiết kế cơ sở dữ liệu

> Nguồn: `init_db` trong `apps/api/omaishort/db.py`.

| Bảng | Cột đáng kể | Không chứa |
| --- | --- | --- |
| `jobs` | id, status, stage, error, input_json, bible_json, structure_json, storyboard_json, timeline_json, artifacts_json, progress, user_id | byte PNG/MP3/MP4 |
| `users` | id, email, password_hash, display_name, role, failed_logins, locked_until | — |
| `refresh_tokens` | id, user_id, token_hash, expires_at, revoked_at, user_agent | token thô |
| `attachments` | id, user_id, kind, filename, mime, byte_size, sha256, rel_path | nội dung file (nằm ở `DATA_DIR/attachments/<user_id>/`) |

Index: `idx_jobs_user (user_id, created_at)`, `idx_attachments_user (user_id, created_at)`.

`user_id` trên `jobs` được thêm bằng `_ensure_column` để DB cũ không phải tạo lại bảng.

File job, tạo bởi `paths.py`:

| Hàm | Đường |
| --- | --- |
| `job_dir` | `data/jobs/<id>/` |
| `stills_dir` | `.../stills/` |
| `audio_dir` | `.../audio/` |
| `render_dir` | `.../render/` (`short.mp4`, `motion.json`, `captions.ass`) |

Ba backend chia sẻ cùng hàm SQL: Postgres (psycopg), SQLite (pytest hoặc `DATABASE_URL` dạng sqlite), D1 (`d1://worker` khi có URL + key Worker). Worker là `apps/cloud` (D1 binding `env.DB`). D1 không đổi schema logic; `schema.sql` tạo cùng bốn bảng.

> ⚠️ Không có migration framework (Alembic). Đổi cột là `_ensure_column` hoặc tạo bảng `IF NOT EXISTS`.
