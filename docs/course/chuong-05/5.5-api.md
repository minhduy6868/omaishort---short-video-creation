# 5.5 Thiết kế API

> Nguồn: `apps/api/omaishort/main.py`. Prefix `/jobs` là API, không phải route UI.

## Công khai (không cần session)

| Method | Path | Việc |
| --- | --- | --- |
| GET | `/`, `/health` | sống |
| GET | `/providers` | `llm_status()` |
| GET | `/voices` | danh sách giọng |

## Cần session (`CurrentUser`)

POST `/providers/chatgpt-login` và `/providers/chatgpt-open`, GET/PUT `/providers/elevenlabs` đều nhận `CurrentUser`. Không nằm ở nhóm công khai.

## Auth và file đính kèm

| Method | Path |
| --- | --- |
| POST | `/auth/register`, `/auth/login`, `/auth/refresh` |
| POST | `/auth/logout` |
| GET | `/auth/me` |
| POST/GET | `/attachments` |
| GET | `/attachments/{id}`, `/attachments/{id}/file` |
| DELETE | `/attachments/{id}` |

## Job

| Method | Path | Việc |
| --- | --- | --- |
| POST | `/jobs` | tạo job từ `StoryInput` |
| GET | `/jobs`, `/jobs/{id}` | danh sách, một job |
| GET | `/jobs/{id}/artifacts` | đường artifact |
| GET | `/jobs/{id}/download` | tải MP4 |
| GET | `/files/{path}` | still/audio đã auth bằng cookie |

Hợp đồng chi tiết auth: `docs/AUTH.md`. Hợp đồng job: `docs/REQUIREMENTS.md` §10.

Studio gọi các path này với `credentials: "include"`. Vite proxy chuyển `/jobs`, `/auth`, `/files` sang API local.

> ⚠️ Không có API version prefix (`/v1`). Không có OpenAPI viết tay ngoài schema FastAPI tự sinh tại `/docs`. Không có webhook khi job xong; client poll.
