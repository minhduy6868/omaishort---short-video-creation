# 5.6 Mẫu thiết kế (Design Patterns)

Chỉ những mẫu nhìn thấy trong code.

| Mẫu | Chỗ | Việc |
| --- | --- | --- |
| Strategy / chuỗi | `ImageProvider` trong `providers/image.py`, chuỗi video trong `providers/video.py` | Đổi nhà cung cấp mà `plan_scenes` không import SDK |
| Adapter | `D1Connection` + `D1Result` trong `d1.py` | Worker HTTP giả cursor `execute / fetchone / fetchall` để `db.py` dùng chung |
| Fallback object | `fallback_analyze`, `fallback_plan` trong `engine/fallback.py` | Khi JSON LLM hỏng, vẫn ra bible và storyboard hợp schema |
| Template giai đoạn | `run_job` | Mọi kind đi cùng thứ tự stage; nhánh editorial chỉ đổi script và nguồn still |

`PlaceholderImageProvider` là chiến lược cuối, không phải null object giấu lỗi: pipeline vẫn ghi provider nào đã chạy.

Mẫu sách thường kể nhưng **không** có lớp riêng trong repo: Singleton, Observer, Abstract Factory đặt tên, Decorator bọc request. Khóa `_lock` trong `db.py` là khóa thread quanh connection, không phải Singleton registry.

Thêm một model ảnh mới là implement `generate(...)` rồi cắm vào chuỗi, đúng luật `.cursor/rules/python-backend.mdc`.
