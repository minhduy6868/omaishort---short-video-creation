# 7.4 Review mã nguồn bằng AI

Review của diff `fix(brief): keep news stills on spoken objects and intact credits` theo câu hỏi cố định. AI được hỏi. Câu trả lời chỉ đứng khi chỉ được dòng code hoặc test.

| Câu hỏi | Kết luận |
| --- | --- |
| Diff có đụng UI không? | Không |
| Có đổi `VideoKind` hoặc biến tin thành drama không? | Không |
| Có provider mới không? | Không |
| Credit tiếng Việt còn bị cắt ở chữ cái ASCII không? | Regex mới gồm `\w` và `À-ỹ`. Test `Minh Bằng` và `*Đình Văn*` |
| Từ khoá `khoảng`, `nguyên`, `phong` còn thành query gara cháy không? | Stop-list và nhánh tên riêng ngắn. Test trong `test_visual_terms_for_beat_follow_the_vo_not_the_headline` |
| Ảnh bài có bị xếp sau Wikimedia khi caption đã khớp không? | `editorial_candidate_score` cộng 0.18 khi trùng ≥ 0.15 và `article=True`. Test caption gara thắng query `portrait flowers` |
| Còn lỗ nào AI dễ bỏ qua? | Có. `gather_external_for_beat` vẫn ghép danh từ thô. Ghi ở [7.3](7.3-code-smells.md), chưa vá |

Review không thay merge. Người đọc diff rồi mới commit. Không có check tự động "AI approve" trên pull request.
