# 8.1 Kiểm thử đơn vị

Một test đơn vị gọi một hàm, không mở server, không gọi mạng.

| File | Số test (đếm `def test_`) | Ví dụ việc |
| --- | --- | --- |
| `tests/test_schema.py` | 11 | Schema từ chối still lẫn trong một cảnh |
| `tests/test_brief_media.py` | 36 | Tách bài báo, từ khoá ảnh, credit, điểm caption, ảnh bài không caption |
| `tests/test_engine.py` | 40 | Fallback analyze/plan, nhịp cuối tin, chấm câu nói, thứ tự giọng TTS |
| `tests/test_agent_pack.py` | 3 | File skill/agent trỏ đúng, không kiểm video |

Bốn file này có 90 trên 144 test. Chúng dùng HTML chuỗi, `tmp_path`, và hàm thuần. `test_photo_credit_keeps_the_next_sentence_intact` nhét một bài giả `fck_detail` rồi gọi `extract_article_text`. Không GET trang báo.

`test_agent_pack.py` cũng là test đơn vị: nó đỏ khi merge `fix/remake-ui` thêm hai skill (`landing-page-design`, `design-to-motion`) mà danh sách trong test chưa có. Test bắt đúng việc nó canh: skill Cursor và con trỏ Codex/Claude phải khớp.

Khi AI đề xuất test đơn vị, assert phải khoá một quy tắc đã viết trong hợp đồng hoặc một bug đã thấy. Assert kiểu "hàm không ném" là chưa đủ.
