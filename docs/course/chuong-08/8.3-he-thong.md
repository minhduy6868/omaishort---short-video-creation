# 8.3 Kiểm thử hệ thống

Repo có hai test đầu gần hệ thống. Cả hai chạy trên máy, không gọi provider.

## Pipeline ra hình đúng kích thước

`tests/test_render.py` (19 test) dựng still PIL, gọi Ken Burns / `compose_short`, rồi `probe_video_size`. Kỳ vọng 1080×1920 và có audio khi bài kiểm tra MP4 đầy đủ. Thoại trong các test này là `silence_audio`, không phải ElevenLabs.

## Studio trong trình duyệt thật

`tests/test_studio_e2e.py` (3 test) mở Chrome headless qua Playwright (đã có trong `requirements.txt` cho hub ChatGPT/Grok, nên không thêm dependency).

Server là bản giống desktop: route API của `omaishort.main` + `attach_studio(app, apps/web/dist)`, chạy uvicorn trên cổng trống, SQLite tạm. App được dựng mới trong test, không gắn route vào `main.app` dùng chung, để test khác không đổi hành vi.

| Test | Người dùng thấy gì |
| --- | --- |
| `test_root_lands_on_vi_and_studio_needs_login` | `/` về `/vi`, theme mặc định `brutal`; `/work` khi chưa đăng nhập về `/login` |
| `test_operator_theme_reaches_every_visitor` | Admin lưu `soft`, một trình duyệt khác mở `/vi` thấy `soft`; `?theme=brutal` chỉ xem thử, tải lại vẫn `soft` |
| `test_only_the_operator_can_click_the_site_theme` | `creator` vào `/account` thấy hai nút theme bị khoá và dòng "Admin (operator) chọn giao diện" |

Test tự skip khi thiếu `apps/web/dist/index.html` hoặc không có Chromium/Chrome/Edge. Thử lần lượt Chromium của Playwright, rồi `channel="chrome"`, rồi `msedge`.

## Vẫn kiểm tay

- Dán URL VnExpress, đợi MP4, đối chiếu năm still với năm câu VO bằng mắt.
- Đo `provider` của ChatGPT web.
- Tắt API giữa chừng: studio phải hiện "Chưa kết nối được API (cổng 8765), đang thử lại…" rồi tự vào khi API lên.

Các việc này kiểm tay khi bảo vệ (tuần 10 trong `docs/course/LO-TRINH.md`). Nếu ảnh vẫn lệch lời, ghi là lỗi còn lại, không gọi là demo cố ý.

> ⚠️ Không có bộ test hệ thống trên staging. Test trình duyệt chạy trên máy dev, chưa chạy trên CI.
