# 8.4 Tự động hóa kiểm thử

File: `.github/workflows/ci.yml`.

| Job | Máy | Lệnh |
| --- | --- | --- |
| `api` | `ubuntu-latest`, Python 3.11 | `pip install -r apps/api/requirements.txt -r apps/api/requirements-dev.txt` rồi `pytest -q` |
| `web` | `ubuntu-latest`, Node 22 | trong `apps/web`: `npm ci` rồi `npx tsc --noEmit` |

Chạy khi push `main` / `master` và khi mở pull request. Không có secret provider. Không có bước GPU, Comfy, FFmpeg bắt buộc.

Job `api` không build web và không cài trình duyệt, nên `test_studio_e2e.py` skip trên CI (pytest in `s`, không phải fail). Muốn CI chạy nó thì job phải thêm `npm ci && npm run build` trong `apps/web` và `playwright install --with-deps chromium`. Chưa thêm, vì làm job chậm thêm vài phút và tải trình duyệt mỗi lần.

Trên máy dev, chạy đủ ba lớp:

```powershell
cd apps\web; npm run build; cd ..\..
apps\api\.venv\Scripts\python.exe -m pytest -q
```

`cd-pages.yml` là deploy landing, không phải cổng test. Đừng thêm pytest vào worker Pages.

AI không được quyền bỏ `pytest -q` để "cho nhanh", và không được thêm dependency test vào `requirements.txt` (luật CI: dep test nằm ở `requirements-dev.txt`). Playwright đã ở `requirements.txt` từ trước vì hub ChatGPT/Grok dùng nó lúc chạy.
