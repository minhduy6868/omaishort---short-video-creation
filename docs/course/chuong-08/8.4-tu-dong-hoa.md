# 8.4 Tự động hóa kiểm thử

File: `.github/workflows/ci.yml`.

| Job | Máy | Lệnh |
| --- | --- | --- |
| `api` | `ubuntu-latest`, Python 3.11 | `pip install -r apps/api/requirements.txt -r apps/api/requirements-dev.txt` rồi `pytest -q` |
| `web` | `ubuntu-latest`, Node 22 | trong `apps/web`: `npm ci` rồi `npx tsc --noEmit` |

Chạy khi push `main` / `master` và khi mở pull request. Không có secret provider. Không có bước GPU, Comfy, Playwright, FFmpeg bắt buộc.

`cd-pages.yml` là deploy landing, không phải cổng test. Đừng thêm pytest vào worker Pages.

AI không được quyền bỏ `pytest -q` để "cho nhanh", và không được thêm dependency test vào `requirements.txt` (luật CI: dep test nằm ở `requirements-dev.txt`).
