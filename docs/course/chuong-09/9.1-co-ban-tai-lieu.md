# 9.1 Cơ bản về tài liệu

Mỗi file một người đọc. Trùng vai thì dễ bị AI viết hai hợp đồng lệch nhau.

| Người đọc | File họ mở trước | Không mở để làm gì |
| --- | --- | --- |
| Người chạy máy | `README.md` | Không sửa số 1080×1920 ở README nếu REQUIREMENTS chưa đổi |
| Người giữ sản phẩm | `docs/REQUIREMENTS.md` | Không lấy RESEARCH làm luật |
| Người giữ tài khoản | `docs/AUTH.md` | Không nhân bản bảng actor vào README |
| Người học môn | `docs/course/chuong-*/` | Không biến bài học thành tính năng |
| Agent sửa code | `AGENTS.md` rồi `.cursor/rules/` | Không copy luật sang một file RULE thứ hai |

Quy tắc khi AI viết thêm tài liệu:

- Câu về hành vi phải chỉ được file code hoặc test.
- Câu đề cương yêu cầu nhưng repo không có thì để ở "Báo cáo thiếu hụt".
- Tiếng Việt trong docs được. Tên hàm, tên file, câu commit giữ tiếng Anh.

`docs/course/LO-TRINH.md` là lịch tuần, không phải hợp đồng. Khi lịch và REQUIREMENTS lệch, giữ REQUIREMENTS.
