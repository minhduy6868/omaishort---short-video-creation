# 9.2 Tài liệu kỹ thuật

Bộ kỹ thuật đã có. Chương 9 không sinh bản thứ hai.

| Loại | File | Nội dung được phép trích khi báo cáo |
| --- | --- | --- |
| Cách chạy | `README.md` §Setup, §Commands, §Tests | venv Windows, lệnh CLI, `pytest` và `tsc` |
| Hợp đồng video | `docs/REQUIREMENTS.md` | 1080×1920, năm nhịp, một still mỗi cảnh, Ken Burns không được gọi là I2V |
| Hợp đồng tài khoản | `docs/AUTH.md` | cookie, job theo user, CLI `user_id` null, file không lên D1 |
| Kiểu dữ liệu | `packages/schema/omaishort_schema/models.py` | `VideoKind`, `StoryInput`, storyboard |
| Prompt | `prompts/*.txt` | chương 2 đã ánh xạ |
| API | `apps/api/omaishort/main.py` | chương 5.5 |
| Vì sao không fork | `docs/RESEARCH.md` | học stage, không copy repo |
| Việc để sau | `docs/ROADMAP.md` | không implement trong bài tài liệu |

D1 (`apps/cloud/schema.sql`) giữ hàng `jobs`, `users`, `refresh_tokens`, `attachments`. Byte still, `audio/voiceover.mp3`, `render/short.mp4` ở `data/jobs/<id>/` trên máy chạy engine.

Landing trên Cloudflare Pages (`apps/landing`, workflow `cd-pages.yml`) là trang giới thiệu. Engine video không chạy trên Worker đó.
