# 9.3 Giao tiếp lập trình và chuyển giao tri thức

Chuyển giao nghĩa là người khác (hoặc chính mình tuần sau) sửa được pipeline mà không hỏi lại từ đầu.

| Kênh | Việc |
| --- | --- |
| `AGENTS.md` | Bảng file nào là nguồn. Mọi agent đọc cùng một bản |
| `.cursor/rules/*.mdc` | Luật pipeline, chất lượng, cách commit, CI |
| `docs/course/chuong-01` … `chuong-09` | Bài môn học bám code. Smell chưa sửa nằm ở chương 7.3 |
| Commit | `type(scope): why`. Chương 2–6 đã tách commit theo chương |
| `script.json` trên một job | `provider` và `note` nói ai đã viết lời. Đó là chuyển giao cho buổi bảo vệ, không phải tài liệu trong git |

Việc người nhận máy phải tự làm, không nằm trong repo:

1. Tạo venv theo README §Setup.
2. `python -m omaishort --chatgpt-login` nếu muốn `provider` khác `wiki`.
3. Điền `.env` (không commit).
4. Render ba job local: drama, tin, kiến thức. MP4 ở `data/jobs/.../render/short.mp4`.

AI viết bài chương này không thay các bước đó. Nếu một đoạn AI bảo "đã có video demo trên server", đó là sai: server Pages không giữ MP4 engine.
