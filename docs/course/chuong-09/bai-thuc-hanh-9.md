# Bài thực hành 9 — Báo cáo ngắn từ file có sẵn

Không tạo file PRD mới. Điền bảng này bằng đường dẫn, mỗi ô một file.

| Câu giảng viên có thể hỏi | Mở file |
| --- | --- |
| Chạy thế nào trên Windows? | `README.md` §Commands |
| Video bắt buộc những gì? | `docs/REQUIREMENTS.md` §0 |
| Ai được đọc job của ai? | `docs/AUTH.md` §2 |
| Còn thiếu gì so với một PRD sách giáo khoa? | `docs/course/chuong-03/README.md`, mục Báo cáo thiếu hụt |
| Ảnh và MP4 có lên D1 không? | `docs/course/chuong-05/5.1-kien-truc.md` |
| Test nào đang chạy trên GitHub? | `.github/workflows/ci.yml` |

Viết nửa trang: sản phẩm làm gì, ba kind, chỗ AI viết lời, chỗ file nằm trên máy. Lấy câu từ các file trên. Không thêm chỉ số doanh thu, không thêm tính năng P3/P6.
